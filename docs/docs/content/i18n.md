# Internationalization (i18n)

AELIG Mail is available in multiple languages thanks to language packs contributed by volunteers. A language pack is a JSON file that maps translation keys to localized text. Bundled language files are stored in the `i18n` directory.

## Additional language packs

Additional language JSON files can be loaded with the `--i18n-dir` flag.

| Language | Description |
| --- | --- |
| Deutsch (formal) | German language with formal pronouns |

## Customizing languages

To customize an existing language or add a new one, edit or add a `.json` language file and pass its directory to AELIG Mail with `--i18n-dir=/path/to/dir`.

## Contributing a new language

Open the [language editor](../../i18n/), create or load a language, translate the text, and download the resulting JSON file. Add it to the `i18n` directory using the project's contribution workflow.
