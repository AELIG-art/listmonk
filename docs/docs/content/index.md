# Introduction

![AELIG Mail](images/logo.svg)

AELIG Mail is a self-hosted, high performance one-way mailing list and newsletter manager. It comes as a standalone binary and the only dependency is a Postgres database.

![AELIG Mail screenshot](https://user-images.githubusercontent.com/547147/134939475-e0391111-f762-44cb-b056-6cb0857755e3.png)

## Developers
AELIG Mail is a free and open source software licensed under AGPLv3. If you are interested in contributing, check out the GitHub repository and refer to the [developer setup](developer-setup.md). The backend is written in Go and the frontend is Vue with Buefy for UI.
